# Shop Data-Flow Tree — always-on pointer

**MANDATORY** before adding a feature or fixing a bug on purchases, inventory, POS, sells, CRM, Quick Assist, or reports.

Read **`AGENT_DATA_FLOW_TREE.md`** (repository root).

Use the existing writer, table, and API in that tree. CRM is the patient record (refills and special orders). Quick Assist shows those same rows. Do not add a second store for a fact the tree already names.
