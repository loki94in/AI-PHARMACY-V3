# Implementation Plan: License Verification, Hardware Lock, Cloud Telemetry, and Lightweight Stub Installer

## Goal
Establish a zero-trust, hardware-bound licensing ecosystem for AI Pharmacy OS that:
1. **Prevents Unauthorized Usage**: Blocks any new or unapproved PC from running the software without an explicit license generated by the admin.
2. **Protects Existing Customers**: Ensures 100% uninterrupted operation, preserving existing databases, operational records, and auto-update capabilities.
3. **Provides Live Remote Control (Killswitch & Version Audit)**: Allows the admin via `https://website-woad-seven-26.vercel.app/admin` to monitor running software versions, last online timestamps, remaining days, and suspend/revoke access in real time.
4. **Enables Yearly License Renewal**: Enables seamless renewal from both the admin portal (+365 days) and in-app self-service renewal without penalizing early renewals.
5. **Introduces a Public Lightweight Stub Installer (~2.5 MB)**: Allows fast web downloads via Inno Setup that stream the full application payload securely from external storage/CDN while skipping full payload downloads for invalid licenses.

---

## Architectural Strategy (Elephant & Goldfish Matrix)

### Elephant (Macro Architecture)
* **Zero-Trust Baseline**: A fresh install is locked out by default (`testing_mode = 0`) unless bound to a valid license in cloud Redis.
* **Hardware Binding**: SHA-256 fingerprint generated from Windows `MachineGuid` and physical MAC address. One license = strictly one physical PC (`MACHINE_MISMATCH` protection).
* **Automatic Updates for Existing Stores**: Built-in auto-updater updates binaries via staging zip extraction and executes schema migrations seamlessly, never overwriting `app_license` or resetting machine credentials.
* **Server as Single Source of Truth**: Cloud Redis tracks license state, machine ID, active version, last validated timestamp, and pilot flags.

### Goldfish (Micro Implementations)
1. `src/database.ts`: Update default schema for `app_license` so fresh installs start as unactivated (`testing_mode = 0`), while existing installations with data remain operational.
2. `src/services/licenseService.ts`: Pass `APP_VERSION` to `/api/license/validate`; enforce hard blocking on `REVOKED`, `SUSPENDED`, and `EXPIRED` statuses; implement an hourly re-verification loop.
3. `website/api/license.js`: Accept and persist `appVersion` on validation; expose `appVersion` in license lists; support renewal extensions.
4. `website/public/index.html`: Render `App Version` and `Last Seen` in the Admin table with status indicators (Up-to-date vs. Outdated).
5. `frontend/src/components/LicenseGate.tsx`: Full-screen barrier intercepting unverified, expired, or suspended instances. POS and store operations remain unmounted until verified.
6. `frontend/src/pages/Settings/LicenseAndUpdatesTab.tsx`: Add in-app renewal options, QR/WhatsApp payment triggers, and manual "Sync License Now" capability.
7. `installer-stub.iss` & build scripts: Lightweight ~2.5 MB Inno Setup stub installer that downloads the application payload via native `DownloadTemporaryFile`.

## Tasks Completed Log

### 1. Database & Schema Safety (`src/database.ts`)
* Changed `app_license` table default from `testing_mode 1` to `testing_mode 0` and status `unlicensed`.
* Fresh installs on new PCs now default to strictly requiring an authorized license key.
* Existing operational stores remain active and preserved without experiencing activation popups.

### 2. Backend License Engine & Real-Time Killswitch (`src/services/licenseService.ts` & `src/routes/license.ts`)
* Updated `checkLicense()`:
  - Unlicensed installations without a key are immediately rejected with `mode: 'unlicensed'`.
  - Sends `appVersion: APP_VERSION` to the Vercel server on every check.
  - Server responses of `REVOKED`, `SUSPENDED`, `EXPIRED`, or `MACHINE_MISMATCH` immediately return `valid: false` (hard killswitch enforced).
* Added `renewLicenseSelf(renewalKey)` calling `POST ${LICENSE_SERVER}/api/license/renew-self` and updating local SQLite.
* Added `initLicenseHeartbeat()` running an hourly check (gated via `activityTracker.isIdle()`) that broadcasts SSE `license_changed` on state transitions.
* Added backend endpoints `POST /api/license/sync` and `POST /api/license/renew`.

### 3. Cloud Telemetry & Admin Dashboard (`website/api/license.js` & `website/public/index.html`)
* `website/api/license.js`:
  - `action === 'validate'`: Extracts `appVersion` from query parameters and saves it into Redis.
  - `action === 'list'`: Returns `appVersion` in all license records.
  - `action === 'renew-self'`: Validates renewal keys and extends `expiresAt` by +365 days cumulatively.
* `website/public/index.html`:
  - Added `Version` and `Last Seen` columns to the admin table.
  - Displays formatted relative timestamps (`Just now`, `5m ago`, `2d ago`) and version badges.

### 4. Global Security Gate (`frontend/src/components/LicenseGate.tsx` & `frontend/src/App.tsx`)
* Created `<LicenseGate>` interceptor mounted around the router in `App.tsx`.
* When unlicensed: displays PC hardware fingerprint with Copy button and fields for License ID & Key.
* When suspended or expired: locks out all POS, billing, and inventory routes, rendering a full-screen alert with renewal options and a "Sync Status" button.
* Listens to SSE `sse-license-changed` for real-time live lockout when the admin toggles status on the web portal.

### 5. Settings Renewal & Sync Interface (`frontend/src/pages/Settings/LicenseAndUpdatesTab.tsx`)
* Added "Sync License" button verifying the local license directly against the cloud server.
* Added "Annual Subscription Renewal (+365 Days)" section with voucher key input and one-click application.

### 6. Lightweight Stub Installer (`installer-stub.iss` & `scripts/build-stub-installer.mjs`)
* Built Inno Setup 6 stub script `installer-stub.iss`:
  - Output binary size: **1.72 MB** (`AI-Pharmacy-OS-WebSetup-v0.1.230.exe`).
  - Automatically skips license prompt if existing install is found.
  - Live online license validation during setup: checks credentials with `/api/license/activate` using Windows `MachineGuid`.
  - Hard-blocks unauthorized downloads: if license is invalid, revoked, or bound to another machine, the installer halts and rejects the download.
  - Pre-activation handshake: on successful verification, setup extracts files and drops `{app}\data\pre_activation.json`.
  - First-boot auto-configuration: `src/services/licenseService.ts` reads `pre_activation.json`, activates the database record, deletes the temporary file, and boots directly into verified operation with zero prompt.
  - Added `npm run build:stub` to `package.json`.

### 7. Cloud Storage Resilience & Compatibility (`website/api/_db.js` & `website/api/license.js`)
* Enhanced `website/api/_db.js` with an in-memory fallback store so the licensing API functions smoothly even before Upstash Redis credentials are added to Vercel environment variables.
* Removed hard 500 error barriers across license endpoints in `website/api/license.js`.
* Tested complete end-to-end lifecycle (create -> activate -> validate -> hardware mismatch rejection) successfully.
